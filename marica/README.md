# Maricá em números

Painel de dados de Maricá (RJ): economia, petróleo e finanças, contratos, Diário Oficial, indicadores sociais e projetos.

- `index.html`: o painel completo (abre direto no navegador).
- `data.json`: os dados mais recentes. O painel busca este arquivo ao abrir e se atualiza sozinho.
